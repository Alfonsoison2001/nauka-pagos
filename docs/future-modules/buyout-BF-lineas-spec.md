# BF — Cómo representar las líneas por partida (spec de Alfonso, 29-jun)

> Criterio EXACTO por partida para el re-volcado de Beachfront. Cada partida = N líneas según
> su número de pptos / torres. El monto por partida debe seguir cuadrando al centavo con el tablero.
> 2 torres. "0.5 cantidad" = 1 ppto que cubre ambas torres, repartido 50/50 (unitario = ppto total).

### Patrones
- **0.5 espejo:** 1 ppto cubre ambas torres → 2 líneas, cantidad 0.5 c/u (Imper, Inst×3, Automat, Aire, Iluminación, Acabados).
- **Por torre real:** 1 ppto por torre, cada línea su monto real (Obra Civil, Albañilería).
- **Por ppto/concepto × torre:** N pptos × 2 torres (Mármol 4, Vidrios 8, Cocinas 6, Jardinería 4, Exteriores 12, Garden 6, Otros 4).
- **Por madurez:** Carpinterías = ppto (2) + paramétrico (2).
- **Por concepto (sin torre):** Arquitectura (2), Ingenierías (detalle).
